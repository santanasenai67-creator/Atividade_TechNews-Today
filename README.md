# TechNews Today

Projeto desenvolvido como atividade prática para criação de um portal de notícias utilizando HTML e CSS.

## 🎯Objetivo

Criar um portal de notícias moderno e responsivo, utilizando recursos de CSS como Glassmorphism, gradientes, CSS Grid, posicionamento sticky e Media Queries.

## 📁Arquivos do projeto

desafio10a.html — Estrutura da página.
10a_desafio.css — Estilização e layout do portal.

## 🚀Tecnologias utilizadas

HTML5
CSS3
CSS Grid
Media Queries
Glassmorphism
Gradientes

## ✅Requisitos da atividade

O projeto deve conter:

Glassmorphism utilizando backdrop-filter;
Gradiente no texto;
CSS Grid para organização do layout;
Header com position: sticky;
Media Query para dispositivos móveis;
No máximo 50 linhas de CSS;
Sem utilização de frameworks;
Sem JavaScript;
Sem alterações no HTML.

## 🎨Layout

O portal possui um header com efeito de vidro fosco, título com degradê e um layout que organiza o vídeo e a newsletter lado a lado.

Além disso, a página foi adaptada para diferentes tamanhos de tela por meio de Media Queries.

## 📤Entrega

O projeto deve ser enviado em um repositório público no GitHub contendo os seguintes arquivos:

desafio10a.html
10a_desafio.css
